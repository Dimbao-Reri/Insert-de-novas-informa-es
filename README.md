# Excel ETL Automation with Python

## Context
Daily workflow problem at my insurance job: new data arrives in Spreadsheet B every day and needs to be merged into Spreadsheet A manually.

## Solution
Python script using **Pandas** to automate the append process — transforming 2+ hours of manual work into a 10-second execution.

## Stack
- Python 3
- Pandas

## How to Run
1. Place both spreadsheets in the same folder
2. Run `python insert_data.py`

## Why this matters
Real-world ETL automation solving a daily business problem — directly transferable to data pipeline workflows.
